Orbit

Privacy policy

Effective 26 November 2026. Published by Zheng Li (MossyWare). Contact: support@mossyware.com.

This policy covers the Orbit day planner on iPhone, Android and the web (on a Chinese home screen the app is named 日晷). This page is the public copy. It does not run the app and it does not receive your plans. Loading it uses the same typefaces as the rest of mossyware.com, from fonts.googleapis.com and fonts.gstatic.com. That request is how the browser fetches the fonts. This page has no account, no analytics and no form.

About this policy

Orbit is a day planner: time blocks, a focus timer, an almanac and optional sound. Support: https://mossyware.com/orbit/. This policy: https://mossyware.com/orbit/privacy/. Account deletion: https://mossyware.com/orbit/privacy#delete-account.

When you sign in with Apple or email, or turn on encrypted sync, the app talks to https://api.orbit.mossyware.com. A guest who never does those things does not need that server.

Information we hold, and why

Plans, task types, focus history and settings
So the day, the timer and your preferences work. They are stored on the device. They are included in the encrypted server copy only if you turn sync on.
Display name
So the app can greet you. It stays on the device. It is not part of the backup file and it is not uploaded.
Birthday, if you add one
To personalise the almanac (your year sign, and how a day relates to it). It stays in the planner file on the device, and inside the encrypted copy if sync is on. Orbit does not use it to check your age.
Language
English, 简体中文 or 繁體中文. Stored on the device. Not uploaded.
Apple or email sign-in
To open a session. The server can hold an account id, the email address Apple or you provided, Apple’s refresh token (so deletion can revoke it), and a hash of the session token. Plans are not part of the sign-in request.
Email sign-in code
To prove you control the address. The server stores the address, a hash of the six-digit code (not the code itself) and the IP address of the request, so it can limit abuse. The code works once and expires after 10 minutes.
Google sign-in
The app keeps Google’s account id, name, email and photo address on the device, to show your name and to keep your plans apart from a guest’s. Orbit’s server is not involved. If a photo address is present, the app loads that image so it can show it.
Encrypted sync, if you turn it on
A copy of the planner file, encrypted on your device, so another device signed into the same Apple or email account can restore it. The server stores ciphertext, a salt and an initialisation vector. It does not receive the recovery code or the planner fields in a readable form.
Reminders, calendar and widgets
To show a block’s title and time, or that a focus session ended, and to mirror blocks into a calendar named “Orbit”. These stay with your phone (and, on iPhone, with iCloud if the Orbit calendar is placed there). They are not sent to Orbit’s server.

What stays on your device

The working copy of your plans is the one on the device. Orbit works without an account. Guest mode keeps the same planner under a guest id on this device. The session token and the sync recovery code, when they exist, are sealed on the device. The recovery code is never sent to the server.

Signing in

Signing in is optional.

Apple. Offered on iPhone and, when a web client is configured, in the browser. Not offered on Android. The app sends Apple’s identity token and a one-time authorisation code to api.orbit.mossyware.com. The server checks the token, keeps Apple’s refresh token so that deleting the account can revoke it, and returns a session. Your plans are not in that request.

Email. The app sends your address to the same server. The server emails a six-digit code that works once and expires after 10 minutes. Delivery is described under service providers. Your display name is not part of this request.

Google. The app receives your Google account id, name, email and photo address and keeps them on the device. Orbit’s server does not take part, and your plans are not sent to Google. Google’s own sign-in services are contacted only when you choose Google. On the web, that sign-in loads a script from accounts.google.com and can request a profile from www.googleapis.com. A production build does not load that script unless a Google web client id is configured. Showing a Google photo loads the image address Google returned, with no referrer sent.

Encrypted sync

Encrypted sync is off unless you turn it on. It is offered only for an Apple or email account. Google sign-in and guest mode do not have it.

When it is on, the planner file is encrypted on your device before upload. The key is derived from a recovery code Orbit shows you once. That file contains your blocks, task types, focus history, settings and birthday if you set one. It does not contain your display name. Only the encrypted copy is uploaded. The developer and the server cannot read it without the recovery code, and the recovery code is not sent to the server.

A lost recovery code cannot be reset. Plans already on the device stay readable. Turning sync off stops further uploads and leaves the server copy in place. Delete encrypted copy removes that copy from the server and keeps the plans on the device.

Reminders

The reminders switch starts on. You can turn it off under Me → Planning. Reminders are scheduled by the phone. Orbit has no push server and does not register a push token. A reminder can show a block’s title and start time, or that a focus session has ended. On Android 13 and later, the system asks for notification permission. Signing out or deleting the account cancels reminders that are still waiting. The microphone is not used. Focus sounds are generated on the device.

Calendar and widgets

Add to Calendar is off until you turn it on. Orbit then asks for calendar access and writes blocks into a calendar of its own named “Orbit”: the title (a finished block is prefixed with a check mark), the start and end, and the type. It reads and updates only events in that calendar. It does not read, change or delete events in your other calendars. Turning the setting off removes the Orbit calendar.

On iPhone, Orbit puts that calendar with your iCloud calendars when it can, so iCloud may keep a copy and show it on your other devices. On Android it stays on the device. Orbit does not send the calendar to its own server.

Home Screen widgets on iPhone show the coming week of blocks, the almanac and the focus timer. Orbit keeps a snapshot for them in storage that the app and its widgets can read. That snapshot can include block titles and times, focus state, and almanac text. If you added a birthday, the almanac text in the snapshot can reflect it. The birthday date itself is not written into the snapshot.

Service providers

Orbit uses these providers to run the service. It does not sell personal information and it does not use it for advertising.

  • Vercel hosts the API in the Sydney region.
  • Neon provides the Postgres database that holds accounts, sessions, sign-in records and encrypted sync copies. The database region is chosen in the hosting configuration; the app source does not name it.
  • Resend sends the sign-in email. It receives your email address and the message, which includes the one-time code.
  • Apple handles Sign in with Apple when you choose it, and may hold the Orbit calendar if it was placed in iCloud.
  • Google handles Google sign-in when you choose it, and serves a profile photo if one is shown.

Your phone’s own backup can include Orbit’s local data. Android backup to the Google account on the device is left on. An iPhone backup made with iCloud or a computer can include it too. Orbit cannot read those backups.

Export, import and phone backups

Export saves your plans, task types, focus history, settings and birthday as a JSON file that you keep. It does not include your display name. Import reads a file you choose and replaces the planner on this device. Orbit does not upload these files. Deleting your account does not delete a backup you already exported, and it does not delete a copy inside a phone backup. If you do not want a restore to bring the data back, remove Orbit from that backup as well.

No tracking

Orbit has no analytics, advertising or third-party crash reporting, and it does not track you across other companies’ apps or websites. Fonts used by the app are bundled with it. Sound is generated on the device. The microphone, camera, photos, location and contacts are not used.

How long we keep it

Plans on the device stay until you clear them, delete the account, or remove the app. An encrypted copy stays on the server until you choose Delete encrypted copy or the server account is deleted. Turning sync off does not delete it.

A sign-in session lasts 30 days, or until you sign out, whichever comes first. The server keeps the account, Apple’s refresh token and session records until that account is deleted. Expired and revoked session rows are removed with the account, not on a separate schedule.

An email code stops working after 10 minutes, or sooner if it is used or checked too many times. The server still keeps the address, the code hash and the request IP until those rows are deleted. They are deleted when account deletion includes that email address. See the deletion steps for the case where it does not.

Children

Orbit is a general day planner. It does not ask your age, it has no children’s account, and the optional birthday is used only for the almanac. It is not a service for children. We do not knowingly collect personal information from children. If you believe a child has given us an email address or an account, email support@mossyware.com and we will delete the account data we hold for that address.

Delete your account and data

These are the steps. The same instructions are on this page at https://mossyware.com/orbit/privacy#delete-account.

In the app

  1. Open the Me tab.
  2. Tap Delete account and data. Guest mode does not show this row, because a guest has no account.
  3. Tap again. The label changes to Tap again to delete for good. If you wait about five seconds, it goes back to the first label and nothing is deleted.

What that does

  • It erases that account’s plans, focus history, settings, birthday and profile from this device, cancels waiting reminders, and signs you out.
  • For Apple and email, if the app still has a sign-in session, it also deletes the account on Orbit’s server: the user, the sign-in identity, sessions and the encrypted copy. It asks Apple to revoke the stored token. Your Apple ID or Google account itself is not deleted.
  • If that server call fails, the app stops and leaves the data on the device. The message is “Couldn’t delete the server account. Nothing was erased on this device.” Check the connection and try again.
  • If the sign-in session has already expired, the app still erases the copy on this device, but it cannot delete the server account by itself. Email us, as below, and we will.
  • If Apple does not confirm the revoke, the app asks you to remove Orbit under Apple ID → Sign-In & Security → Sign in with Apple. The Orbit account is still deleted.
  • Google sign-in has no Orbit server account. Deletion clears Orbit’s data on this device and signs out of Google inside the app. It does not delete the Google account.

Guest mode

There is no account to delete. Leave guest mode signs out of the guest session and cancels waiting reminders. It does not erase the guest plans; they come back if you continue as guest again. Clear all plans removes blocks and tray tasks and keeps task types, birthday and settings. The first time you sign in, guest plans are copied to that account if it is empty, and the guest planner file is then removed. To remove everything stored for the guest, uninstall Orbit or clear its storage.

What can remain

  • A JSON backup you exported, and any copy in an iPhone or Android backup. Deleting the account does not remove those.
  • The “Orbit” calendar, if Add to Calendar was on. Turn that setting off before you delete the account, or delete the Orbit calendar in the Calendar app. An iCloud copy can remain on other devices until you remove it there.
  • The iPhone widget snapshot, until Orbit is opened again and writes a new one. Until then the widgets can still show the previous blocks.
  • Sign-in code records (email address, code hash and request IP) are removed when deletion includes that address. The current server reads the address from an Apple identity. An email-only account’s old sign-in records can therefore remain after the account row is deleted. Email us and we will delete them.

If you cannot use the app

Email support@mossyware.com with the subject “Orbit account deletion”. Include the email address you used, or say whether you used Apple or Google and on which device. We will delete the server account we can match, including any encrypted copy and remaining sign-in records for that address. To remove data from a device you still have, uninstall Orbit or clear its storage. That does not, by itself, delete a server account.

Changes

If this policy changes, the date at the top of this page will change. A material change will also be described in the app.

生效日期：2026 年 11 月 26 日。发布者：Zheng Li（MossyWare）。联系：support@mossyware.com。

本政策适用于 iPhone、Android 和网页版的 Orbit（中文主屏幕名称为日晷）。本页是公开文本，不运行 App，也收不到你的计划。页面字体与 mossyware.com 其余页面相同，由浏览器向 fonts.googleapis.com 和 fonts.gstatic.com 请求。本页没有账号、没有统计、也没有表单。

支持页面：https://mossyware.com/orbit/。本政策：https://mossyware.com/orbit/privacy/。删除账号：https://mossyware.com/orbit/privacy#delete-account。使用 Apple 或邮箱登录，或开启加密同步时，App 会连接 https://api.orbit.mossyware.com。游客若不使用这些功能，就不需要这台服务器。

我们保存什么，以及为什么

计划、任务类型、专注记录和设置
用来显示你的一天、计时和偏好。保存在设备上。只有在你开启同步后，才会进入服务器上的加密副本。
显示名称
用来向你问好。只留在设备上，不在备份文件里，也不会上传。
生日（如果你填写）
用来让黄历显示你的年属，以及当天与你的关系。保存在设备上的计划文件里；开启同步后也会在加密副本里。Orbit 不用它核对年龄。
语言
English、简体中文或繁體中文。保存在设备上，不上传。
Apple 或邮箱登录
用来建立会话。服务器可以保存账号 ID、Apple 或你提供的邮箱、Apple 的刷新令牌（以便删除账号时撤销），以及会话令牌的哈希。这次请求不含计划。
邮箱验证码
用来确认你能收到该邮箱的邮件。服务器保存邮箱地址、6 位验证码的哈希（不保存验证码本身）和请求的 IP 地址，用于限制滥用。验证码只能用一次，10 分钟后失效。
Google 登录
App 把 Google 账号 ID、姓名、邮箱和头像网址保存在设备上，用来显示名字，并和游客的计划分开。Orbit 的服务器不参与。如果有头像网址，App 会加载那张图片以便显示。
加密同步（如果你开启）
计划文件先在你的设备上加密，以便同一 Apple 或邮箱账号在另一台设备上恢复。服务器只保存密文、盐和初始向量，收不到恢复码，也看不到可读的计划内容。
提醒、日历和小组件
用来显示任务块的标题和时间，或提示专注结束，并把任务块写入名为「Orbit」的日历。这些留在手机上（iPhone 上若日历放进 iCloud，则由 iCloud 保存）。不会发给 Orbit 的服务器。

留在设备上的内容

正在使用的计划是设备上的那一份。不登录也能使用。游客模式把同样的计划保存在这台设备的游客身份下。会话令牌和同步恢复码（如果有）会封存在设备上。恢复码不会发给服务器。

登录

登录是可选的。

Apple。 提供于 iPhone；网页版仅在配置了网页客户端时提供。Android 上不提供。App 把 Apple 的身份令牌和一次性授权码发到 api.orbit.mossyware.com。服务器核对令牌，保存 Apple 的刷新令牌，以便删除账号时撤销，并返回会话。请求里没有你的计划。

邮箱。 App 把邮箱地址发到同一台服务器。服务器发一封含 6 位验证码的邮件，验证码只能用一次，10 分钟后失效。显示名称不在这次请求里。

Google。 App 收到 Google 账号 ID、姓名、邮箱和头像网址，并保存在设备上。Orbit 的服务器不参与，计划也不会发给 Google。只有在你选择 Google 时才会联系 Google。网页版会从 accounts.google.com 加载脚本，并可向 www.googleapis.com 请求资料。生产构建在没有配置 Google 网页客户端 ID 时不会加载该脚本。显示 Google 头像时会加载 Google 返回的图片地址，并且不发送引荐来源。

加密同步

加密同步默认关闭，只有 Apple 或邮箱账号可以开启。Google 登录和游客模式没有这项功能。

开启后，计划文件会在设备上加密再上传。密钥由只显示一次的恢复码生成。这份文件包含任务块、任务类型、专注记录、设置，以及你填写的生日。它不包含显示名称。上传的只有密文。没有恢复码，开发者和服务器都无法读取；恢复码也不会发给服务器。

恢复码丢失后无法重置。已经在设备上的计划仍可阅读。关闭同步会停止继续上传，服务器上的副本还在。「删除加密副本」会删掉服务器上的副本，并保留设备上的计划。

提醒

提醒开关默认开启，可以在「我的 → 规划」里关闭。提醒由手机自己排程。Orbit 没有推送服务器，也不登记推送令牌。提醒可能显示任务块的标题和开始时间，或提示专注已经结束。Android 13 及更高版本会询问通知权限。退出登录或删除账号会取消尚未触发的提醒。从不使用麦克风。专注的声音在设备上生成。

日历与小组件

「同步到系统日历」默认关闭。开启后，Orbit 请求日历权限，把任务块写入名为「Orbit」的独立日历：标题（已完成的任务块前面会加勾）、开始和结束时间，以及类型。它只读取和更新这个日历里的事件，不读取、不修改、也不删除你其他日历里的日程。关闭这项设置会移除 Orbit 日历。

在 iPhone 上，Orbit 会尽量把这个日历放进 iCloud，因此 iCloud 可能保存一份并显示在其他设备上。在 Android 上，它只留在这台设备。Orbit 不会把日历发给自己的服务器。

iPhone 主屏幕小组件显示接下来一周的任务块、黄历和专注计时。Orbit 把一份快照放在 App 和小组件可以读取的存储里。快照可以包含任务块的标题和时间、专注状态和黄历文字。如果你填了生日，快照里的黄历文字可能据此生成，但生日日期本身不会写进快照。

服务提供方

Orbit 使用这些提供方来运行服务。我们不出售个人信息，也不把它用于广告。

  • Vercel 在悉尼区域托管 API。
  • Neon 提供 Postgres 数据库，保存账号、会话、登录记录和加密同步副本。数据库所在区域由托管配置决定，App 源代码里没有写明。
  • Resend 发送登录邮件。它会收到你的邮箱地址和邮件内容，其中包含一次性验证码。
  • Apple 在你选择「通过 Apple 登录」时处理登录；若 Orbit 日历放进了 iCloud，也可能由 Apple 保存。
  • Google 在你选择 Google 登录时处理登录，并在显示头像时提供图片。

手机自己的备份可能包含 Orbit 的本地数据。Android 备份到设备上的 Google 账号保持开启。用 iCloud 或电脑做的 iPhone 备份也可能包含它。Orbit 读不到这些备份。

导出、导入与手机备份

导出会把计划、任务类型、专注记录、设置和生日保存成一个由你保管的 JSON 文件，其中没有显示名称。导入会读取你选择的文件，并替换这台设备上的计划。Orbit 不会上传这些文件。删除账号不会删除你已经导出的备份，也不会删除手机备份里的副本。如果不希望恢复时把数据带回来，请同时从那份备份里移除 Orbit。

不追踪

Orbit 没有统计分析、广告或第三方崩溃报告，也不会跨其他公司的应用或网站追踪你。App 使用的字体随应用打包。声音在设备上生成。不使用麦克风、相机、照片、位置或通讯录。

保存多久

设备上的计划会一直保留，直到你清空、删除账号或卸载 App。加密副本会留在服务器上，直到你选择「删除加密副本」或服务器账号被删除。关闭同步不会删除它。

登录会话保留 30 天，或直到你退出登录，以先到者为准。服务器会保留账号、Apple 刷新令牌和会话记录，直到该账号被删除。过期和已撤销的会话行会随账号一起删除，没有单独的清理日程。

邮箱验证码在 10 分钟后失效；如果已经使用或错误尝试次数过多，会更早失效。服务器仍会保留邮箱地址、验证码哈希和请求 IP，直到这些记录被删除。当删除账号时带有该邮箱地址，这些记录会被删除。若没有带上地址，见下面的删除步骤。

儿童

Orbit 是面向一般用户的日程应用。它不询问年龄，没有儿童账号，可选的生日只用于黄历。它不是面向儿童的服务。我们不会在知情的情况下收集儿童的个人信息。如果你认为有儿童向我们提供了邮箱或账号，请发邮件到 support@mossyware.com，我们会删除我们为该地址保存的账号数据。

删除账号和数据

英文部分的 Delete your account and data 是带有 delete-account 锚点的步骤。简体步骤如下，与之相同。

在 App 里：

  1. 打开「我的」。
  2. 点「删除账号和数据」。游客模式没有这一项，因为游客没有账号。
  3. 再点一次。文字会变成「再点一次，永久删除」。如果大约五秒内没有再点，会回到原来的文字，什么都不会删除。

这会做什么：从这台设备上抹去该账号的计划、专注记录、设置、生日和资料，取消尚未触发的提醒，并退出登录。如果是 Apple 或邮箱账号，并且 App 里还有登录会话，还会删除 Orbit 服务器上的账号（用户、登录身份、会话和加密副本），并请 Apple 撤销已保存的令牌。你的 Apple ID 或 Google 账号本身不会被删除。

如果服务器没有成功删除，App 会停下来，设备上的数据保持原样，并提示无法删除服务器账号、本机什么都没有抹掉。请检查网络后再试。如果登录会话已经过期，App 仍会抹掉这台设备上的副本，但无法自行删除服务器账号，请按下面的方式发邮件，由我们删除。

如果 Apple 没有确认撤销，App 会请你到 Apple ID 的「登录与安全性」→「通过 Apple 登录」里移除「日晷」（Orbit）。Orbit 账号本身仍会被删除。Google 登录没有 Orbit 服务器账号；删除只会清掉这台设备上的 Orbit 数据，并在 App 内退出 Google，不会删除 Google 账号。

游客：没有账号可删。「退出游客模式」会退出游客会话并取消尚未触发的提醒，但不会抹掉游客的计划；再次以游客身份继续时，计划还在。「清空所有计划」会去掉任务块和托盘里的任务，并保留任务类型、生日和设置。第一次登录时，如果该账号还是空的，游客计划会被复制过去，然后游客的计划文件会被删除。要去掉游客在设备上的全部内容，请卸载 Orbit 或清除它的存储。

登入是可選的。

Google。 App 收到 Google 帳號 ID、姓名、電子郵件和頭像網址，並保存在裝置上。Orbit 的伺服器不參與，計畫也不會發給 Google。只有在你選擇 Google 時才會聯絡 Google。網頁版會從 accounts.google.com 載入指令碼，並可向 www.googleapis.com 請求資料。生產組建在沒有設定 Google 網頁用戶端 ID 時不會載入該指令碼。顯示 Google 頭像時會載入 Google 返回的圖片位址，並且不傳送引用來源。

加密同步

加密同步預設關閉，只有 Apple 或電子郵件帳號可以開啟。Google 登入和遊客模式沒有這項功能。

開啟後，計畫檔案會在裝置上加密再上傳。金鑰由只顯示一次的恢復碼生成。這份檔案包含任務區塊、任務類型、專注記錄、設定，以及你填寫的生日。它不包含顯示名稱。上傳的只有密文。沒有恢復碼，開發者和伺服器都無法讀取；恢復碼也不會發給伺服器。

恢復碼遺失後無法重設。已經在裝置上的計畫仍可閱讀。關閉同步會停止繼續上傳，伺服器上的副本還在。「刪除加密副本」會刪掉伺服器上的副本，並保留裝置上的計畫。

提醒

提醒開關預設開啟，可以在「我的 → 規劃」裡關閉。提醒由手機自己排程。Orbit 沒有推送伺服器，也不登記推送權杖。提醒可能顯示任務區塊的標題和開始時間，或提示專注已經結束。Android 13 及更高版本會詢問通知權限。退出登入或刪除帳號會取消尚未觸發的提醒。從不使用麥克風。專注的聲音在裝置上生成。

日曆與小工具

「同步到系統日曆」預設關閉。開啟後，Orbit 請求日曆權限，把任務區塊寫入名為「Orbit」的獨立日曆：標題（已完成的任務區塊前面會加勾）、開始和結束時間，以及類型。它只讀取和更新這個日曆裡的事件，不讀取、不修改、也不刪除你其他日曆裡的行程。關閉這項設定會移除 Orbit 日曆。

在 iPhone 上，Orbit 會盡量把這個日曆放進 iCloud，因此 iCloud 可能保存一份並顯示在其他裝置上。在 Android 上，它只留在這台裝置。Orbit 不會把日曆發給自己的伺服器。

iPhone 主畫面小工具顯示接下來一週的任務區塊、黃曆和專注計時。Orbit 把一份快照放在 App 和小工具可以讀取的儲存裡。快照可以包含任務區塊的標題和時間、專注狀態和黃曆文字。如果你填了生日，快照裡的黃曆文字可能據此生成，但生日日期本身不會寫進快照。

服務提供方

Orbit 使用這些提供方來執行服務。我們不出售個人資訊，也不把它用於廣告。

  • Vercel 在雪梨區域代管 API。
  • Neon 提供 Postgres 資料庫，保存帳號、工作階段、登入記錄和加密同步副本。資料庫所在區域由代管設定決定，App 原始碼裡沒有寫明。
  • Resend 傳送登入郵件。它會收到你的電子郵件地址和郵件內容，其中包含一次性驗證碼。
  • Apple 在你選擇「透過 Apple 登入」時處理登入；若 Orbit 日曆放進了 iCloud，也可能由 Apple 保存。
  • Google 在你選擇 Google 登入時處理登入，並在顯示頭像時提供圖片。

手機自己的備份可能包含 Orbit 的本機資料。Android 備份到裝置上的 Google 帳號保持開啟。用 iCloud 或電腦做的 iPhone 備份也可能包含它。Orbit 讀不到這些備份。

匯出、匯入與手機備份

匯出會把計畫、任務類型、專注記錄、設定和生日保存成一個由你保管的 JSON 檔案，其中沒有顯示名稱。匯入會讀取你選擇的檔案，並替換這台裝置上的計畫。Orbit 不會上傳這些檔案。刪除帳號不會刪除你已經匯出的備份，也不會刪除手機備份裡的副本。如果不希望恢復時把資料帶回來，請同時從那份備份裡移除 Orbit。

不追蹤

Orbit 沒有統計分析、廣告或第三方當機報告，也不會跨其他公司的應用或網站追蹤你。App 使用的字型隨應用打包。聲音在裝置上生成。不使用麥克風、相機、照片、位置或通訊錄。

保存多久

裝置上的計畫會一直保留，直到你清空、刪除帳號或解除安裝 App。加密副本會留在伺服器上，直到你選擇「刪除加密副本」或伺服器帳號被刪除。關閉同步不會刪除它。

登入工作階段保留 30 天，或直到你退出登入，以先到者為準。伺服器會保留帳號、Apple 重新整理權杖和工作階段記錄，直到該帳號被刪除。過期和已撤銷的工作階段列會隨帳號一起刪除，沒有單獨的清理日程。

電子郵件驗證碼在 10 分鐘後失效；如果已經使用或錯誤嘗試次數過多，會更早失效。伺服器仍會保留電子郵件地址、驗證碼雜湊和請求 IP，直到這些記錄被刪除。當刪除帳號時帶有該電子郵件地址，這些記錄會被刪除。若沒有帶上地址，見下面的刪除步驟。

兒童

Orbit 是面向一般使用者的行程應用。它不詢問年齡，沒有兒童帳號，可選的生日只用於黃曆。它不是面向兒童的服務。我們不會在知情的情況下收集兒童的個人資訊。如果你認為有兒童向我們提供了電子郵件或帳號，請寄信到 support@mossyware.com，我們會刪除我們為該地址保存的帳號資料。

  1. 打開「我的」。
  2. 點「刪除帳號和資料」。遊客模式沒有這一項，因為遊客沒有帳號。
